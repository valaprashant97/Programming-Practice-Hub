# Bubble Sort

## Aim
To sort an array of elements in ascending order using the Bubble Sort algorithm.

## Introduction
Bubble Sort is a simple sorting algorithm that repeatedly compares adjacent elements and swaps them if they are in the wrong order.

## Algorithm
1. Start from the first element.
2. Compare adjacent elements.
3. Swap them if the first element is greater than the second.
4. Repeat until the largest element moves to the end.
5. Continue until the array is sorted.

## Example

**Input:** `5, 3, 8, 2, 1`

**Pass 1:** `3, 5, 2, 1, 8`

**Pass 2:** `3, 2, 1, 5, 8`

**Pass 3:** `2, 1, 3, 5, 8`

**Pass 4:** `1, 2, 3, 5, 8`

**Output:** `1, 2, 3, 5, 8`

## Advantages
- Easy to understand and implement.
- Requires no extra memory for sorting.
- Suitable for small datasets.

## Disadvantages
- Slow for large datasets.
- Performs many comparisons and swaps.
- Less efficient than advanced sorting algorithms.

## Applications
- Sorting small arrays or lists.
- Learning basic sorting concepts.
- Sorting data when simplicity is more important than speed.

## Time Complexity
- Best Case: O(n) (optimized version)
- Average Case: O(n²)
- Worst Case: O(n²)

## Space Complexity
- O(1)

## Conclusion
Bubble Sort arranges elements in ascending order by repeatedly comparing and swapping adjacent elements.
